1つむぎってどんなアプリ？

まずは「つむぎ」がどんなアプリで、なぜこの名前なのかをご紹介します。

「つむぎ」は、デイサービス（通所介護）の毎日の記録・運営をまとめて行えるアプリです。 利用者さんのバイタル（体温・血圧など）や運動記録、連絡帳、スケジュール管理、ご家族との情報共有まで、 紙やバラバラの表で行っていた作業を 1 つにまとめます。パソコン・タブレット（iPad）・スマホのどれでも使えます。

🍀 名前の由来

「つむぎ（紡ぎ）」は、糸を紡（つむ）ぐことから来ています。 ご利用者・ご家族・現場のスタッフを、1 本ずつの糸のように、やさしく丁寧につないで（紡いで）いく—— そんな想いを込めて名づけました。ロゴの四つ葉のクローバーは「しあわせ」と「みんなのつながり」を表しています。

つむぎは、ご利用者を真ん中に、ご家族とスタッフをつなぎます

2ログインする

事業所から渡された ID とパスワードでログインします。
  1. ブラウザ（Safari や Chrome）で、事業所のつむぎのURLを開きます。
  2. 「事業所ログイン（スタッフ専用）」の画面で、ログインID と パスワードを入力します。
  3. ログイン ボタンを押します。
事業所ログイン画面のイメージ
ID・パスワードを忘れたら画面下の 📧 support@ones-style.co.jp までご連絡ください。

3画面の見方

左の「サイドバー」からやりたいことを選びます。よく使う機能はこの中にあります。
左：サイドバー（メニュー）／ 右：選んだ画面
全画面表示記録入力などでは右上の ⛶ 全画面 を押すと、表が大きく見やすくなります。元に戻すときは ⛶ 通常 を押します。
スマホ・iPadの方へ画面が狭いときは、左上の ≡（三本線）でサイドバーを開け閉めできます。

4「スタッフ切替」で担当者を選ぶ

記録を入力する前に、「今、記録している人（担当者）」を選んでおきます。記録に担当者名が残ります。
  1. サイドバーの スタッフ切替 を押します。
  2. 今から入力する担当者の名前を選びます。
  3. これで、保存する記録にその担当者名が自動で入ります。
担当者が未選択のまま保存すると「担当者が設定されていません」と確認が出ます。なるべく先に担当者を選んでから入力しましょう。

5利用者マスタ管理

ご利用者の基本情報・緊急連絡先・ケアマネ情報などを登録・編集します。

① 1人ずつ登録する

  1. サイドバー 利用者マスタ管理 → 右上の ＋ 新規利用者 を押します。
  2. 姓・名・姓フリガナ・名フリガナを入力して 追加する。
  3. 一覧から本人を選び、生年月日・介護度・利用開始日・住所などを入力します。
  4. 入力が終わったら、右上の 💾 保存 を必ず押します。

② CSVでまとめて取り込む（おすすめ）

たくさんの利用者を一度に登録するなら、エクセル等のCSVファイルから取り込めます。介護ソフト（カイポケ等）の書き出しCSVも、そのまま読み込めます。

  1. 利用者マスタ管理の CSV入出力 を開きます。
  2. 初めてなら テンプレート をダウンロードし、エクセルで入力 → 保存します。
  3. CSVファイルを選択 でファイルを選び、内容を確認して 取り込み。
かしこい仕組み列の名前が多少違っても自動で見分けて取り込みます。文字コード（Shift-JIS/UTF-8）も自動判定。空欄の項目は上書きしません（記入した項目だけ反映）。氏名は自動で姓・名に分かれます。

③ 緊急連絡先（ご家族）

ご家族がアプリに登録すると、その情報（姓・名・フリガナ・続柄・電話・メール）が、利用者マスタの 「緊急連絡先（主要）」欄に自動で反映されます。2人目以降は「追加の緊急連絡先」に並びます。 もちろんスタッフが直接入力・修正することもできます。

④ お休み（休止）の登録

  1. 本人の 状態 を 休止 にするか、月間スケジュールのセルから休止期間を登録します。
  2. 休止期間の開始日（必要なら終了日）と理由を入れて登録します。
退所と完全削除のちがい「退所（利用終了）」は記録を残します。「完全削除」は利用者と関連データ・写真ファイルをすべて消去します（元に戻せません）。

6サービス提供記録入力（毎日の記録）

その日のご利用者ごとに、体温・血圧・脈拍・運動・気分・特記などを入力します。
記録表のイメージ。数字のマスを押すとテンキーが出ます

入力のしかた

  1. サイドバー 提供記録入力 を開き、日付が今日になっているか確認します。
  2. 体温・血圧・脈拍などのマスを押すと、画面にテンキー（数字パッド）が出ます。数字を押して入力します。
  3. 血圧は「上／下」をまとめて入力できます（例：128/80）。
  4. 気分のマスを押すと、😊などの絵で気分を選べます。理由も選べます。
  5. 運動・特記事項なども入力します。
  6. すべて終わったら、右上の 💾 保存 を押します。
テンキーは動かせます邪魔なときは、テンキー上部の ≡ を押したまま動かして移動、＋／−で大きさも変えられます。
保存はその日ごと記録は「表示している日」を保存すると残ります。前の日の分は、その日に切り替えてから保存してください。保存した分は自動でクラウドに保存され、分析にも反映されます。

7月間スケジュール・休止

「基本利用曜日」をもとに、1か月の利用予定を自動でつくります。増減や振替もできます。
  1. サイドバー 月間スケジュール を開きます。
  2. セルを押して、その日の利用（AM/PM）・欠席・振替・休止などを設定します。
  3. 基本利用曜日を増やす／減らすときは、「いつから適用するか（適用開始日）」を選びます。 過去の予定はそのまま、その日以降にだけ反映されるので安心です。
増回・減回もカレンダーで分かる「○月○日から週◯回に増えた」といった変更が、カレンダー上でも確認できます。

8ご家族アカウントの招待・管理

ご家族・ご関係者（ケアマネ等）が、記録や写真を見られる専用アカウントを発行します。
  1. 利用者マスタ管理で本人を選び、アカウント管理 を押します。
  2. 招待を発行すると、招待URL（または招待コード）が作られます。
  3. そのURLを、ご家族にメール・LINE・紙などで伝えます（有効期限あり）。
  4. ご家族が自分で ID・パスワード・連絡先を登録すると、利用が始まります。
2人目以降もOK同じ利用者に対して、複数のご家族・ケアマネを招待できます。最初に登録した方が「主要連絡先」になります。
見える範囲ご家族には、その利用者の記録・連絡帳・写真・お知らせが見えます。他の利用者の情報は見えません。

9連絡帳・お知らせ・個人ファイル・分析

📒 連絡帳・日誌

その日の様子をご家族向けに記録します。印刷・PDF・FAX送付にも対応しています。

📢 お知らせ・写真

事業所からのお知らせや、行事の写真をご家族へ配信できます。全員向け／特定の方向けを選べます。 消したお知らせ・写真は7日間ゴミ箱に残り、戻すこともできます。

📁 個人ファイル（フェイスシート等）

フェイスシート・契約書・ケアプラン・モニタリング・既往歴・かかりつけ医・ジェノグラム/見取り図/送迎経路の画像など、 利用者ごとの書類をまとめて保管できます（画像・PDFはクラウドに安全に保存）。

📊 分析

利用者ごと・期間ごとに、バイタルの推移や利用状況をグラフで確認できます。 利用開始前の期間は集計から自動で除かれます。

10データの保存とバックアップ

入力したデータは自動でクラウド（Supabase）に保存されます。
  • 保存ボタンを押すと → すぐクラウドへ保存されます。
  • 入力途中などの自動保存は、約1.5秒後にまとめて送られます。
  • 通信が不安定なときは、誤って空データで上書きしない安全装置が働き、数秒後に自動で再保存します。

手動バックアップ（ZIP）

各種設定 → データ管理 → 📦 データ一括エクスポート（ZIP） で、 利用者一覧や記録をまとめてダウンロードして保管できます。大切なデータは定期的に保存しておくと安心です。

11困ったときは

  • テンキーが出ない／表示が崩れる … 画面を一度更新（リロード）してみてください。
  • データが古い気がする … 少し待つと自動で最新に更新されます。改善しなければリロードを。
  • ログインできない … ID・パスワードをご確認のうえ、下記サポートへ。
