1つむぎとは（名前の由来）

「つむぎ」がどんなアプリで、なぜこの名前なのかをご紹介します。

「つむぎ」は、デイサービス（通所介護）の毎日の記録・運営をまとめて行えるアプリです。バイタル・運動記録、連絡帳、スケジュール、ご家族との情報共有までを 1 つに。パソコン・iPad・スマホのどれでも使えます。

🍀 名前「つむぎ（紡ぐ）」の由来

「つむぎ」は、糸を紡つむぐ——細い糸を寄り合わせ、一本の丈夫な糸にすることが由来です。デイサービスでは、事業所・ご家族・ケアマネジャー・その他関係者（訪問看護 等）が、それぞれの立場から一人のご利用者を支えています。つむぎは、そのバラバラになりがちな情報や想いを一本に紡ぎ、事業所とご家族とケアマネをやさしくつなぐことを目指したアプリです。

ロゴの四つ葉のクローバーは、その想いをかたちにしたものです。中心の黄色い円がご利用者、4枚の葉がご家族・ケアマネ・事業所・その他関係者。みんなが中心のご利用者を囲み、毎日の記録・連絡帳・写真を通じて様子を紡ぎ合わせ、離れていても安心を分かち合います。四つ葉の花言葉「幸運」のように、関わる方すべてに小さな安心が届くように——それが「つむぎ」です。

中心のご利用者を、ご家族・ケアマネ・事業所・その他関係者の四つ葉が囲んで支えます。その一人ひとりの想いと記録を“紡ぐ”のが「つむぎ」です。

2ログインする

事業所から渡された ID とパスワードでログインします。
  1. ブラウザで事業所のつむぎのURLを開きます。
  2. 「事業所ログイン」画面で ログインID と パスワードを入力。
  3. ログイン を押します。
ID・パスワードを忘れたら画面下の 📧 support@ones-style.co.jp へご連絡ください。

3画面の見方・全画面・固定バー

左の「サイドバー」からやりたいことを選びます。
全画面表示記録入力などは右上の ⛶ 全画面 で表が大きく。戻すときは ⛶ 通常。
上部バー（期間・利用者選択・ジャンプ等）はスクロールしても上に固定されます。iPad で一部固定されない場合は画面を一度更新（リロード）してみてください（改善を継続中です）。

4スタッフ切替（担当者）

記録の前に「今、記録している担当者」を選びます。記録に担当者名が残ります。
  1. サイドバーの スタッフ切替 を押す。
  2. 今から入力する担当者を選ぶ。一覧に居なければ ＋ スタッフを追加。
日誌だけに居る人も追加できます「日誌」に登録済みの方でも、スタッフ切替に居なければ追加できます（同じ名前で重複登録はされません）。
未選択のまま保存すると確認が出ます。先に担当者を選んでから入力しましょう。

5利用者マスタ管理

ご利用者の基本情報・緊急連絡先・ケアマネ情報を登録・編集します。

① 1人ずつ登録

  1. 利用者マスタ管理 → ＋ 新規利用者。
  2. 姓・名・姓フリガナ・名フリガナを入力して 追加する。
  3. 生年月日・介護度・利用開始日・住所などを入力し、右上の 💾 保存。
検索が便利に上の検索欄に名前を入れると候補が出て、選ぶとその方を開けます。フリガナは入力すると自動でカタカナになります。

② CSVで一括取り込み・書き出し

介護ソフト（カイポケ等）の書き出しCSVもそのまま読み込めます。CSV入出力 → テンプレ取得 → 入力 → 取り込み。列名が多少違っても自動判別、空欄は上書きしません。

  • 対応項目が充実… 氏名・フリガナ・性別・生年月日・住所・電話・緊急連絡先に加え、メール・認定有効期間・負担割合・担当ケアマネ事業所/担当者/電話/FAXも取り込み・書き出しできます。
  • 氏名が重複したとき… 取り込み画面で「置き換える（更新）」か「両方残す（新規追加）」を選べます。置き換えるを選ぶと、空欄だった項目はCSVの値で埋まり、新しい情報はそのまま更新され、重複が増えません。
  • 書き出したCSVをExcelで編集し、再取り込みすれば一括変更もできます。

③ 緊急連絡先・ケアマネ・その他関係者

ご家族・関係者がアプリ登録すると、その情報（姓名・フリガナ・続柄・電話・メール）が「緊急連絡先（主要）」に自動反映。2人目以降は「追加の緊急連絡先」に並びます。

  • 担当ケアマネ… 事業所電話・担当者の直通電話・FAXを表示。担当者を選ぶと直通電話も自動で入ります（各種設定の担当者に直通電話を登録）。
  • その他関係者（訪問看護 等）… ケアマネの下に専用欄。その他関係者がアカウント登録すると自動で追加（関係者名・種別・事業所・電話・FAX）。手動追加・編集・削除も可。

④ お休み（休止）・退所・削除

状態を 休止 にして期間・理由を登録。退所は記録を残し、完全削除は関連データ・写真をすべて消去（元に戻せません）。

⑤ 重複した利用者を「統合」する

同じ方を誤って2件登録してしまった場合、上部の 重複 ボタンで氏名が同じ利用者をまとめて表示。残す1人を選んで統合すると、もう一方のサービス提供記録・連絡帳・体力測定・初回報告・月間スケジュール等の記録はすべて残す側へ引き継がれ（記録は消えません）、空欄は相手の情報で補完されます。

📋 初回ご利用報告新規ご利用から間もない方には名簿に 「📋初回報告」バッジが付きます。作成は §13 の個人ファイルから（バイタル・運動記録を自動取り込み）。
家族アカウントの整理重複した家族アカウントは アカウント管理 から削除できます（削除すると同じIDで再登録できます）。

6サービス提供記録 入力

その日のご利用者ごとに、体温・血圧・脈拍・運動・気分・特記を入力します。
  1. 提供記録入力 を開き、日付が今日か確認。
  2. 数字のマスを押すとテンキーが出ます。血圧は「上／下」をまとめて（例: 128/80）。
  3. 気分のマスを押すと、絵文字で気分を選べます（画面上部に利用者名を表示）。通所時／帰宅時それぞれに合った理由候補（各約10個）から選べます。
  4. すべて終わったら右上の 💾 保存。
テンキーは上部の ≡ で移動、＋／−で大きさ変更。タップしたマスに重ならない位置に出ます。選択中のマスの利用者が青くハイライトされます。
運動の単位数字を入れると単位（分 等）が自動で付きます。×・ー などの記号は単位を付けません。介護整体の「確認」を押すと過去の担当者が最前面に出ます。
保存はその日ごと「表示している日」を保存すると残り、分析にも反映されます。保存ボタンですぐクラウド保存。複数台で同時に入力しても、保存した内容が空欄で上書きされて消えることはありません。

7サービス提供記録（月表・印刷）

月単位の提供記録の確認・印刷、月次スナップショットの作成ができます。
  • サイドバー サービス提供記録 で、利用者・月を選んで一覧表示。
  • 右上のジャンプから他画面へ素早く移動できます。
  • 月次スナップショットは、毎月自動で前月分が作られます（個人ファイルにも保存）。
  • 全期間PDF… 上部の 全期間PDF で、その利用者の全期間の提供記録を1つにまとめて表示。別タブで開くので、ブラウザの「PDFとして保存」でまとめて複数ページのPDFにできます。
  • 運動項目を変更しても安心… 各月は「その月に有効だった運動項目」で表示されます。各種設定で項目を追加・削除しても、過去の月は当時の項目構成のまま表示され、列ズレやエラーになりません（項目の変更は「いつから適用するか」を選べます）。

8月間スケジュール・休止

「基本利用曜日」をもとに1か月の予定を自動作成。増減・振替・休止も。
  1. 月間スケジュール を開く。
  2. セルを押して 利用(AM/PM)・欠席・振替・休止 を設定。
  3. 基本利用曜日の増減は「いつから適用するか」を選択。過去はそのまま、その日以降にだけ反映されます。
振替セルには「振替」とだけ表示し、カーソルを合わせると振替元の日付が出ます。振替を設定するとその場でクラウド保存され（保存ボタン不要）、振替元の日は欠席として提供記録入力にも表示されます。
基本利用曜日の変更・振替は即保存適用した瞬間にクラウドへ保存されるため、利用者を切り替えても消えません。

9連絡帳（作成・印刷・用紙向き）

その日の様子をご家族向けに記録し、印刷・PDF・FAXできます。
  1. 連絡帳 作成・印刷 を開き、日付・利用者を選んで内容を入力。
  2. 用紙の向きを選びます（プレビュー横の 🖨 用紙）。
  3. プレビュー → 印刷 / PDF保存。
用紙の向きの使い分け
・横（B5）… 複合機がB6に対応していない場合。B5用紙の中央に連絡帳を配置して印刷します（連絡帳の中身は縦のまま）。
・縦（B6）… B6対応の複合機がある場合。連絡帳サイズそのままで印刷できます。
コツB6対応の複合機が無ければ「横（B5）」を選び、B5用紙にそのまま印刷すれば、中央にきれいに収まります。
📱 iPadで印刷するとき「印刷・FAX・PDF」を押すと表だけのきれいな別タブが開きます。そのタブ上部の 🖨 印刷 / PDF保存 を押して印刷してください。用紙サイズ・向き（提供記録＝横向き／連絡帳B5＝用紙B5＋横向き）はiPadの印刷画面で選びます（多くの機種では前回設定が記憶されます）。
連絡事項（旧：ご家族からの連絡欄）
上部の 連絡事項 ボタン、または連絡帳の「連絡事項」欄をタップすると編集できます。
・👥 全員への連絡事項＝全利用者の連絡帳に表示（例：負担割合証のご提出のお願い）。
・👤 個別＝利用者をプルダウンで選んで、その方だけに表示（名前の横の●は連絡事項が入っている目印）。
・リッチ入力＝文字を選択（ドラッグ）してから「太字／下線／色（赤・青・緑・黒＋自由な色）／大きさ（小・中・大）」を押すと、その部分だけ装飾できます。重要な一語だけ赤太字、などが可能です。
・📝 定型文＝＋登録で「タイトル＋内容」を登録。📋一覧から、各定型文の適応／編集／削除ができます。適応を押すと「👥全員へ／👤個別へ」を選んで本文に差し込めます。
・表示期間＝「本日のみ／1週間／期間選択（開始〜終了を指定）」。期間外になると自動で消えるので毎回消す手間がありません。
※ 欄からはみ出す（見切れる）量になると警告が出ます。

12ご家族・関係者アカウント

ご家族・ケアマネ・関係者が記録や写真を見られる専用アカウントを発行します。
  1. 利用者を選び アカウント管理 → 招待を発行。
  2. 招待URL（またはコード）を、ご家族へメール・LINE・紙で伝えます（有効期限あり）。
  3. 相手が ID・パスワード・連絡先を登録すると利用開始。
ご家族は代表者＋2名までご家族側からは代表者がさらに2名まで追加できます。3人目以降や、ケアマネ・その他関係者の追加は事業所側で招待を発行してください。
関係者の種類登録時の続柄で ご家族 / ケアマネージャー / その他関係者（訪問看護 等） を選べます。ケアマネ・その他関係者は「関係者一覧」に表示され、ケアマネは利用者のケアマネ情報・各種設定のケアマネ事業所/担当者にも自動反映されます。
ログインIDの変更アカウント管理 の登録済アカウントで ✏ を押すとログインIDを変更できます（重複IDは登録できません）。ケアマネ・その他関係者のアカウントには所属事業所名（🏢）も表示されます。
お知らせ・写真の送付先を選べます家族関係者閲覧 管理 の投稿画面で、👪ご家族／📋ケアマネ／🤝その他関係者を個別に選択（「全員に送る」も可）。例：イベントは「ご家族・ケアマネ」だけに送り、その他関係者には送らない、といった出し分けができます。
「個別に表示」は送付先ごとに対象を選べます
・👪ご家族…利用者名で選択
・📋ケアマネ…事業所を選んでから担当者を選択（その担当者が受け持つ利用者へ届きます）
・🤝その他関係者…登録済みの関係者の一覧から選択
送付先を複数選ぶと、それぞれの選び方が並んで表示されます。
🔧 管理者プレビュー（ご家族・ケアマネ画面の確認）ご家族・ご関係者専用ログイン画面で、本部の管理者ID・パスワード（各事業所のログインでは不可・本部のみ）を入力すると、「ご家族画面」「ケアマネ画面」を閲覧専用でデモ確認できます。個人情報保護のため、実在の利用者ではなく架空（見本）の利用者・ケアマネ・記録で表示されます（ご家族に見える内容や雰囲気をその場で確認したいときに便利）。画面上部にプレビュー表示が出ます。

13個人ファイル・モニタリング

利用者ごとの書類をまとめて安全に保管します。
  • 利用者を選び 個人ファイル へ。フェイスシート・契約書・ケアプラン・既往歴・かかりつけ医・ジェノグラム/見取り図/送迎経路の画像などを保管（画像・PDFはクラウド保存）。
  • 📢 初回ご利用報告… 個人ファイルの 「7. 初回ご利用報告」タブで作成。初回通所のバイタル・運動記録が自動で入り、報告者はスタッフ切替で選んでいる人が初期値（プルダウンで変更可）。印刷・PDF保存もでき、保存すると名簿のバッジが消えます。
  • モニタリング で経過記録を作成・印刷できます。

14分析（個人・稼働）

バイタルの推移や稼働状況をグラフで確認します。
  • 分析（個人）… 利用者・期間を選び、体温・血圧などの推移を確認。検索欄は候補から選べます。グラフは線を太く・点を大きく・タップで数値表示に対応（高齢の方も見やすく）。
  • 血圧・脈の「通所時／終了時／両方」切替… 運動後（終了時）の血圧・脈も測っている場合、グラフ上のボタンで切り替えられます（終了時は点線）。平均・最高・最低も選んだ表示に連動します。終了時を測らない事業所ではボタンは出ません。
  • 今回の様子… 最新の特記を上部にまとめて表示します（「今回の記録」内の特記と重複しないよう一本化）。気分は絵文字＋理由も表示されます。
  • 分析（稼働）… 通所率・出欠などの全体傾向を確認。内訳に「振替」も表示。
  • 振替＝出席扱い… 振替した方は出席としてカウントし、振替元の欠席と相殺します（例：振替のみの方は出席率100%）。曜日別は実際に来た（振替先の）曜日に出席が計上されます。
  • 利用開始前の期間は集計から自動で除かれます。

15各種設定

事業所情報や各種マスタ、運動メニュー、ケアマネ事業所などを管理します。
  • 施設情報… 事業所名・休業日・各種加算 等。
  • 運動メニュー / 個別運動… 記録入力のテンキー項目を管理。
  • ケアマネ事業所・担当者… CSV一括取り込み、法人ごとのグループ表示、検索（候補表示）に対応。電話・FAXは自動でハイフン。✏ で編集でき、編集するとその事業所/担当者を設定している全利用者の担当ケアマネ情報も自動で更新されます。
  • 連絡帳の用紙向き… 横(B5)/縦(B6) を選択（連絡帳画面からも変更可）。
  • アドオン（オプション機能）… ご契約中のオプション機能の一覧を確認できます。ON/OFFの切替は本部が行います（店舗側は表示のみ）。
  • データ管理… ZIP一括エクスポート（バックアップ）。
本部メニュー（複数店舗管理）本部アカウントでは登録店舗一覧から、店舗名・短縮名・法人名・住所・電話・FAXを ✏️ 編集 で後から変更できます（店舗IDは変更不可）。アドオンは各種設定の「アドオン」タブで店舗ごとに有効化できます。

16個別機能訓練計画書（アドオン）

個別機能訓練加算の計画書を作成・印刷します（「アドオン」を有効にした店舗のみメニューに表示）。
  1. サイドバー 個別機能訓練計画書 を開き、上部で利用者を選択。
  2. ＋ 新規作成 で入力。基本情報・本人/家族の希望・健康状態・長期/短期目標・機能訓練プログラム・生活機能5領域への働きかけ・評価/方針を記入します。
  3. 運動メニューから取込 を押すと、その方の予定運動メニューがプログラム欄に自動で入ります（時間・回数つき）。既往・留意点も利用者マスタから自動補完。
  4. 💾 保存 後、🖨 印刷/PDF でA4の計画書を出力。
更新（3ヶ月ごと等）一覧の 複製して更新 で前回内容を引き継いで新しい計画書を作成できます（評価欄はクリア）。

関連書類（タブで切替）

画面上部のタブで、同じ利用者の関連書類を行き来できます。

  • 計画書（様式3-3）… 個別機能訓練計画書 本体。
  • 生活機能チェック（様式3-2）… 起居動作・ADL・IADL・心身機能を自立度で評価し、課題を整理。計画書作成の前提資料。
  • 興味・関心（様式3-1）… 約36項目の生活行為を「している／してみたい／興味がある」でチェック（項目追加も可）。目標設定や社会参加の把握に活用。
様式について厚労省の個別機能訓練計画書（LIFE一体型様式）および別紙様式3-1・3-2を参考にした項目構成です。提出前に最新の公式様式・自治体の指定に合わせてご確認ください。

17保存・バックアップ

  • 保存ボタン → すぐクラウドへ。入力途中の自動保存は約1.5秒後にまとめて送信。複数台で同時に使っても記録ごとにマージされ、上書きで消えません。
  • 通信が不安定な時は空データで上書きしない安全装置が働き、数秒後に自動再保存します。
  • 入力画面は「保存」を押すまで端末内のみ。万一の取りこぼし防止として、アプリ切替・タブを閉じる・スリープに入った瞬間に自動保存します。とはいえこまめに「保存」を押すのが一番確実です。
  • 手動バックアップ… 各種設定 → データ管理 → 📦 ZIP一括エクスポート。定期的な保存をおすすめします。

18困ったときは

  • 表示が崩れる/固定されない … 画面を一度更新（リロード）。
  • データが古い気がする … 少し待つと自動更新。改善しなければリロード。
  • 同じIDが使えない … アカウント管理で重複アカウントを削除してから再登録。
