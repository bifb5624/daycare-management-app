1「つむぎ」とは

デイサービスの記録を、関係機関の方が確認・共有できるアプリです。

「つむぎ」は、デイサービス（通所介護）の記録を、ケアマネジャーや訪問看護などの関係者が確認できるアプリです。担当ご利用者の体温・血圧・運動・気分・体力測定などを、いつでもスマホやパソコンで確認できます。

🍀 名前「つむぎ（紡ぐ）」の由来

「つむぎ」は、糸を紡つむぐ——細い糸を寄り合わせて一本の丈夫な糸にすることが由来です。デイサービスでは、事業所・ご家族・ケアマネジャー・その他関係者が、それぞれの立場から一人のご利用者を支えています。つむぎは、その情報を一本に紡ぎ、事業所とご家族とケアマネをやさしくつなぐアプリです。

ロゴの四つ葉のクローバーは、その4つの存在を表します。中心の黄色い円がご利用者、4枚の葉がご家族・ケアマネ・事業所・その他関係者。みんなで中心のご利用者を支える姿で、あなたも、その大切な一枚です。

中心のご利用者を、ご家族・ケアマネ・事業所・その他関係者の四つ葉が囲んで支えます。その一人ひとりの想いと記録を“紡ぐ”のが「つむぎ」です。あなたも、その大切な一枚です。

2招待からの登録・ログイン

事業所から届いた招待から、はじめの登録をします。

はじめての登録

  1. 事業所から届いた招待のURL（メール等）を開きます。
  2. ご自身で決めたログインIDとパスワードを入力。
  3. 続柄で 「ケアマネージャー」 または 「その他関係者（訪問看護 等）」 を選びます。
  4. お名前・フリガナ・個人の電話番号（ご登録者情報）を入力。
  5. 事業所情報を入力します：
    ・ケアマネ… 一覧から事業所を選択（無ければ新規作成し、固定電話・FAXを入力）。
    ・その他関係者… 事業所名・電話・FAXを自由記述（任意）。
  6. 利用規約に同意して 登録。そのままログインされます。
担当者欄はありません担当ケアマネは「ご登録者情報」のお名前・電話がそのまま使われ、ご利用者のケアマネ情報に自動反映されます。

2回目以降

  1. ログインページで、登録したID・パスワードを入力して ログイン。
招待URLには期限があります切れた場合は事業所へ再発行をご依頼ください。

3ご利用者の記録を見る

ログインすると、担当ご利用者の記録が確認できます。
  1. ログイン後、上部に「今回の様子」（その日の特記）、続いて気分（絵文字＋理由）・体温・血圧・今回の運動メニュー（前回比つき）・体力測定が表示されます。
  2. 下にスクロールで、お知らせ・写真などを確認。
  3. 日付や期間を変えると過去の記録・推移グラフもさかのぼれます。グラフの点をタップすると数値が出ます。運動後（終了時）の血圧も測っている事業所では「通所時／終了時／両方」を切り替えられます。
  4. 気分トレンド… 期間中にいちばん多かった気分の絵文字を「🏢通所時 最多／🏠帰宅時 最多」として、体温などの平均・最高・最低と同じ場所に表示します。
「今回の様子」に注目その日に特に伝えたいことは画面上部の「今回の様子」に集約して表示されます（下の記録に同じ内容が重複しないよう一本化しています）。
閲覧専用関係者の画面は記録の閲覧が中心です（ご自身の連絡先・所属情報の編集のみ可能）。お知らせは事業所の設定により、関係者向けに送られたもののみ表示されます。
担当者会議などの「【予定】…」のお知らせ… 事業所が予定を日時入りでお知らせすることがあります（例：「【予定】担当者会議 ／ 7月10日(金) 14:00〜15:00」）。ケアマネジャーの方は、担当利用者に関する会議日程などのご確認にお使いください。
📖 ご利用ガイドはいつでもログイン後の画面いちばん下に「ケアマネ・関係者向けご利用ガイド」ボタンがあり、このガイドをいつでも開けます。

4複数のご利用者を切り替える

複数のご利用者を担当している場合の切り替え方です。

同じメールアドレス・パスワードで複数のご利用者ぶんの招待を登録すると、1回のログインで切り替えて閲覧できます。

  1. ログインすると、まずそのIDのご利用者の画面に入ります。
  2. 画面の 利用者切替 から、他の担当ご利用者へ切り替えます。
正しいご利用者に入りますログインしたIDのご利用者へ必ず直接入るようになっています。別の方の閲覧は「利用者切替」から行ってください。

5ご自身・所属事業所の情報

電話番号や所属事業所が変わったら、ご自身で更新できます。
  1. 利用者・登録者情報 → 登録者基本情報 を開く。
  2. 姓・名・フリガナ・続柄・電話番号・所属事業所名を確認・修正。
  3. 💾 保存 を押すと、事業所側にも反映されます。
続柄「ケアマネージャー」「その他関係者」から選べます。一覧に無い関係（例: 訪問看護・地域包括 等）は「その他」で自由に入力できます。

6フェイスシートの登録・更新（ケアマネの方）

担当ケアマネの方は、ご利用者のフェイスシート（基本情報の書式）を登録・更新できます。入力内容は事業所の個人ファイルに自動で反映されます。
  1. 画面上部の 📝 フェイスシート を押します。
  2. 受付・家族構成・介護保険・医療（主治医・服薬・アレルギー等）・生活歴・ニーズ・その他などを入力します。
  3. ジェノグラム・自宅見取り図・送迎経路などは写真やPDFを添付できます。
  4. 保存 を押すと、事業所側の個人ファイル（フェイスシート）に反映されます。
変更履歴（版）… 保存するたびに版（バージョン）が記録されます。事業所側にも「最終更新者・版番号・ケアマネ更新あり」が表示されるので、いつ・誰が更新したかが分かります。事業所側でも追記・修正できます。
保存した内容は事業所と共有されます。個人情報の取り扱いにご注意ください。

7保険証・負担割合証・アセスメントの共有（ケアマネの方）

介護保険証・負担割合証・アセスメントシートを、事業所と相互に共有できます。ケアマネが添付すると事業所の個人ファイルに反映され、事業所が更新するとケアマネ画面に新着通知が届きます。
  1. 画面上部の 📎 保険証・アセスメント を押します。
  2. 介護保険証・負担割合証は ＋ 写真・PDFを追加 から添付します（複数可）。
  3. 保険証の内容として 介護度・認定有効期間・負担割合 を入力できます。入力した内容は事業所の利用者マスタ（介護度・認定有効期間・負担割合）に自動で反映されます。
  4. アセスメントシートは文章を手入力でき、写真・PDFの添付もできます。
  5. 保存して事業所に反映 を押すと、事業所側の個人ファイル・利用者マスタに反映されます。
お互いに最新を共有… 既存の書類は上書きされず追記されます。事業所が保険証・負担割合証・フェイスシート・アセスメントを更新すると、画面上部に 🔔「事業所から書類の更新があります」 と表示されます。確認 を押すと消えます。
保険証・負担割合証などは個人情報です。取り扱いにご注意ください。

8困ったときは

  • ログインできない … ID・パスワードをご確認のうえ、事業所へ。
  • 別のご利用者に入ってしまう … 「利用者切替」で正しい方を選んでください。
  • 招待URLが切れた … 事業所へ再発行をご依頼ください。
まずは担当事業所へご不明な点は、ご利用のデイサービス事業所へお問い合わせください。
